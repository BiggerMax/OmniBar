# OmniBar — Omniroute macOS Menu Bar Manager

**One-Liner:** 轻量 macOS 菜单栏工具，管理本地的 Omniroute AI 网关，实时显示 Token 开销、服务状态、Provider 健康度，支持一键切换路由策略。

## User Stories

1. **As a** 日常用户, **I want** 菜单栏图标直接显示今日 Token 消耗/费用, **so that** 我不用打开任何面板就能看到花了多少钱。
2. **As a** 日常用户, **I want** 点击菜单栏图标弹出面板查看服务状态, **so that** 一眼确认 Omniroute 是否正常运行。
3. **As a** 日常用户, **I want** 在面板里一键切换 Combo 路由策略, **so that** 不同场景（coding / cheap / fast）快速切换，不用进 Dashboard。
4. **As a** 日常用户, **I want** 看到所有 Provider 的健康状态列表, **so that** 及时发现哪个 Provider 挂了或配额用完。
5. **As a** 日常用户, **I want** 从菜单栏一键启动/停止 Omniroute, **so that** 不用开终端敲命令。
6. **As a** 日常用户, **I want** 开机自动启动 Omniroute + 本工具, **so that** 每天打开 Mac 就能直接用。

## Pages/Screens

### 1. 菜单栏图标 (NSStatusItem)
- **动态图标**: 基础图标 + 状态圆点（绿/红/黄）
- **Token 开销文本**: 直接显示在菜单栏，如 `$0.42` 或 `12.5K tok`，可选开关
- **右键菜单**: 启动 | 停止 | 重启 | 打开 Dashboard | 偏好设置 | 退出

### 2. Popover 主面板
- **四区块布局**（从上到下）:
  - **状态卡片**: 服务状态（运行中/已停止）、运行时长、端口、版本号
  - **Provider 健康列表**: 精简列表，每行显示 Provider 名称 + 状态徽章（✓ 健康 / ⏳ 冷却 / 🔒 锁定 / ✗ 离线）
  - **Combo 选择器**: 下拉选择器，列出所有可用 Combo，当前选中高亮
  - **用量速览**: 今日 Token 消耗 / 本月预算 / 预估节省，迷你进度条

### 3. 偏好设置页面 (Settings)
- **通用**: 开机自启开关、菜单栏显示 Token 开关
- **连接**: Omniroute 端口（默认 20128）、API Key（可选）
- **关于**: 版本号、GitHub 链接

## Data Logic

### 核心实体
OmnirouteService (进程管理)
├── status: running / stopped / error
├── pid: Int?
├── port: Int (默认 20128)
├── uptime: TimeInterval
├── start() -> Bool
├── stop() -> Bool
└── restart() -> Bool

Provider (来自 API GET /api/providers)
├── id: String
├── name: String
├── status: healthy / cooldown / locked / offline
├── quotaRemaining: Int?
├── quotaTotal: Int?
└── latency: Int? (ms)

Combo (来自 API GET /api/combos)
├── id: String
├── name: String
├── strategy: String (auto / priority / cost-optimized ...)
├── isActive: Bool
└── models: [String]

UsageStats (来自 API 聚合)
├── todayTokens: Int
├── todayCost: Decimal
├── monthTokens: Int
├── monthBudget: Decimal
├── savedTokens: Int
└── savedCost: Decimal

*.txt
Plaintext
### 数据流
1. 工具启动 → 读取配置 → 检查 Omniroute 进程是否运行
2. 如果运行 → 通过 `localhost:20128` 轮询 API（每 10-30s）
3. 获取 Provider / Combo / Usage 数据 → 更新 @Published 属性 → UI 刷新
4. 菜单栏 Token 文本每秒更新（从 UsageStats 取今日数据）
5. 用户操作（启动/停止/切换 Combo）→ 调用 Shell 命令或 API → 更新状态
## Non-Functional Requirements
- **技术栈**: SwiftUI + AppKit (NSStatusItem), 最低 macOS 14+ (Sonoma)
- **性能**: 菜单栏文本更新不影响 UI 流畅度，后台轮询使用异步 Task
- **体积**: 目标 < 5MB，纯原生无额外依赖
- **启动**: 应用启动 < 1s，不得阻塞登录
- **错误处理**: Omniroute 未运行时优雅降级，显示"服务未启动"而非崩溃
